# Новое заведение за 6 минут

Одна установка обслуживает все заведения: новое заведение — это папка `tenants/<slug>/` и публикация.
Адрес для гостей — `/s/<slug>/`, кабинет — `/s/<slug>/owner/`. Данные заведений изолированы в БД.

## 0. Что попросить у заведения

Название и короткое имя для иконки (до 12 символов), адрес, телефон, Telegram, цвет бренда,
юрлицо и ссылка на политику обработки персональных данных, часы работы, залы (вместимость,
сколько гостей входит в цену, доплата за гостя, минимальная длительность, шаг, время на уборку/протопку),
цены (будни / выходные / ночь), допы, задаток и условия отмены, фото залов, логотип/иконка, почта владельца.

## 1. Создать (≈ 30 с)

```bash
npm run tenant:new -- berezka --name "Баня «Берёзка»"
```

Появится `tenants/berezka/business.json` из шаблона и картинки-заглушки.

## 2. Заполнить (≈ 3 мин)

- `business.json`: деньги — целые рубли (`*_rub`), время — `ЧЧ:ММ` по местному времени заведения.
  `working_hours` — окна **моментов начала** брони; `max_end_after_close_min` — насколько бронь может
  закончиться позже. Тариф — правила по типу дня, покрывающие сутки без дыр (ночь `22:00–02:00` допустима).
  Поменять цены после первых броней — добавить новую версию тарифа с более поздней `effective_from`.
- `images/`: `icon-512.png` (512×512 PNG), `icon-maskable-512.png` (512×512, фон до краёв, логотип
  в центральных 80 %), фото залов `halls/<ключ зала>/*.jpg` (≥ 800×450, до 3 МБ).

## 3. Проверить (≈ 10 с)

```bash
npm run tenant:validate -- berezka
```

Ошибки — исправить. Предупреждения с пометкой «мешает --live» (заглушки example.com, телефон
`000-00-00`, «Фамилия/Демо» в юрлице) можно оставить для пробного запуска.

## 4. Опубликовать (≈ 30 с)

```bash
npm run build
npm run tenant:publish -- berezka
npm run tenant:verify -- berezka
```

Заведение в статусе `preview`: им можно пользоваться, уведомления не отправляются, брони помечены как демо.
Повторный `publish` безопасен: брони, платежи и блокировки не трогаются.

## 5. Владелец и запуск (≈ 1 мин)

```bash
npm run owner:invite -- berezka owner@example.ru
npm run tenant:publish -- berezka --live
```

`--live` откажет, пока нет владельца или остаются заглушки. Владелец входит по ссылке из письма на
`/s/berezka/owner/`. Ссылку для гостей и QR-код можно раздавать сразу.

## Изменения потом

Поправить `business.json` или картинки → `tenant:validate` → `tenant:publish`. Убранный из конфига зал
или доп скрывается, но не удаляется; publish предупредит, если у скрытого зала есть будущие брони.
