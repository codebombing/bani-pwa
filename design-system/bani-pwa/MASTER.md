# Дизайн-система — Bani PWA (MASTER)

> Страница из `design-system/bani-pwa/pages/<page>.md`, если есть, переопределяет правила ниже.

**Происхождение.** `ui-ux-pro-max --design-system` на запросы «wellness sauna booking dark warm» и
повторный узкий поиск не дал проверенного совпадения (предлагал светлую розово-лавандовую палитру
и запрет тёмной темы). Поэтому это **общие рекомендации**: правила скила (Quick Reference §1–§9) +
тема Astryx `neutral` в тёмном режиме + акцент заведения из `business.json`.

## Характер
Тёмный, спокойный, плотный, «банный»: тёплые серые поверхности, один тёплый акцент заведения,
выразительные фото залов. Мобильный сценарий первичен (375 px), десктоп — та же колонка ≤ 640 px.

## Цвет
- База — токены темы Astryx `neutral` (`mode="dark"`). Никаких hex в компонентах.
- Акцент — `theme.accent` заведения → `defineTheme({ extends: neutral, tokens: {'--color-accent', '--color-on-accent'} })`
  на рантайме (`src/features/booking/TenantTheme.tsx`). Цвет текста на акценте выбирается по контрасту (≥ 4.5:1).
- Статусы: success/warning/error токены Astryx, всегда вместе с текстом (не только цвет).

## Типографика
Шрифты темы `neutral` (Figtree). Тело ≥ 16 px. Цены — `hasTabularNumbers`. Заголовки: h1 — название
заведения/брони, h2 — шаг/секция. Последовательная иерархия без пропусков.

## Отступы и формы
Шкала Astryx (`gap`/`padding` 1–10). Секции экрана — `gap={6}`, внутри карточек — `gap={2..3}`.
Компоненты: `Card`/`ClickableCard` для залов, `List`/`Item` для слотов и строк, `MetadataList` для деталей,
`BottomSheet` — единственный «drawer» в приложении.

## Поток брони (одна последовательная bottom sheet)
зал → дата → время и длительность → гости и допы → контакты → подтверждение.
- Каждый шаг — свой `BottomSheet` с `label`; одно состояние `step` (замена шага в одном обновлении).
- Кнопка «Назад» в каждом шаге; системный Back закрывает шаг, а не приложение (history state).
- Формы — `purpose="form"` (данные не теряются от свайпа), видимые подписи, ошибки у поля.
- Одна основная кнопка на шаг, внизу; во время запроса — `isLoading`.
- Цена всегда серверная (quote/availability), с разбивкой строк в подтверждении.
- Согласие на обработку ПДн — обязательный чекбокс со ссылкой на политику заведения.

## Состояния каждого сетевого экрана
loading — `Skeleton` по форме контента; error — `Banner status="error"` + «Повторить»;
empty — `EmptyState` с действием; success — контент.

## Доступность и касания
Цели касания ≥ 44 px (Astryx), видимый фокус, `prefers-reduced-motion` (Astryx), safe-area insets
(`global.css`), `interactive-widget=resizes-content` для клавиатуры, телефон — `type="tel"` + `autoComplete`.

## Анти-паттерны
Свои `<div>`/hex/px вместо компонентов и токенов; эмодзи как иконки; модальные окна поверх bottom sheet;
цена, посчитанная на клиенте; скрытые причины недоступности слота без текста.
